# ESP32 USB Serial 設定工具

`esp32_serial_tool_app.exe` 是獨立的 Windows 圖形程式，用來透過 USB 設定 CVTA ESP32 讀卡端。它不連接後端、不代替讀卡機打卡，也不修改電腦上的考勤資料。執行時須保留同一資料夾內的 `_internal/`；工具只把 Serial 回覆顯示在視窗中，不儲存指令、Wi-Fi 密碼或回覆紀錄。

## 連接讀卡機

1. 用 USB 線接上 ESP32，啟動工具，選擇讀卡機的 COM 埠；未列出時按「重新掃描」，或手動輸入 `COM7` 這類埠名。
2. 關閉 Arduino Serial Monitor 等已占用該埠的程式，按「連接」。工具使用固定的 **115200 baud、8N1**。開啟 COM 埠可能使 ESP32 重新啟動；等待下方出現開機文字後，再按「診斷與進階 → status」確認 UUID、Wi-Fi、核准狀態、時間、儲存區和佇列。
3. 拔除 USB 或裝置斷線時，畫面會顯示錯誤並切回未連接；確認 COM 埠後重新連接。完成操作後按「斷線」。

## 校正 LCD

1. 在「LCD 校正」按「讀取 display」確認目前的方向和偏移，再按「顯示定位框」。檢查白框四邊、四色角標與 `TOP` 是否完整且位於上方。
2. 選方向 `0` 正常、`1` 左右鏡像、`2` 上下鏡像、`3` 旋轉 180°，分別用水平與垂直欄位設定 `0–128` 的偏移。每次按「套用」後，工具會送出 `m` 或 `o`，接著讀取 `display` 顯示裝置回報值；畫面也會立即重畫。
3. 調整完成後按「關閉定位框」。定位框約 30 秒後或有新狀態時也會自行結束。重新啟動讀卡機並再次讀取 `display`，確認設定已保存。

現場原模組 PCB 絲印 V2 的參考值為 `m 0`、`o 0 32`；更換後 PCB 絲印 V1.1 的參考值為 `m 3`、`o 2 3`。仍須依實際白框校正。

## 網路、名稱與卡號

- 在「裝置設定」輸入 SSID 和密碼，按「儲存 Wi-Fi」。密碼欄會遮蔽文字，送出後立即清空；畫面上的送出紀錄也不顯示密碼。若韌體回報連線失敗，檢查 SSID、密碼和現場網路。
- 伺服器位址使用 `http://主機:埠`，例如 `http://192.168.1.10:16688`，不要加 `/api/v1`。變更位址會讓裝置重新檢查註冊和核准；在後台讀卡端管理核對 `status` 所示 UUID，確認已核准。
- 輸入設備名稱並按「儲存名稱」。已註冊裝置的後台名稱如需變更，仍須在管理頁修改。
- 沿用既有卡號時，在「既有 UID」填入同一張實卡原有的 8、14 或 20 位十六進位 UID，按「開始 UID 校正」，於 60 秒內刷該卡。只有讀卡機顯示 `UID MATCH` 才可正式打卡；`UID MISMATCH` 時先檢查卡片與舊 UID，不要直接重新綁卡。

## 診斷與進階指令

「診斷與進階」可執行 `help`、`status`、`queue`、`bad`、`poll`、`selftest`，下方視窗持續顯示裝置原始回覆與非同步狀態。進階欄位可輸入一行既有韌體指令，工具會加 LF 行尾；Wi-Fi 密碼必須使用遮蔽表單。手動送出 `init-storage NEW` 或 `discard-bad <id>` 前，工具會要求再次確認。這些指令可能初始化裝置儲存區或永久刪除壞事件，應先確認離線事件狀態。USB 工具不會保存或復原 LittleFS 資料。

`queue` 顯示的待補送事件不代表已入庫。正式刷卡會先存到 ESP32 LittleFS，經 Wi-Fi 對後端 `/api/v1/punch` 發出帶裝置簽章的請求；後端確認裝置已核准且未暫停後才會寫入 SQLite。網路中斷時由相同裝置身分補送。用實卡驗收時，須在管理頁核對紀錄與 `queue`，不能只看工具的 Serial 回覆。

若畫面無回覆，先確認選對 COM 埠、韌體已啟動且其他 Serial Monitor 已關閉；重新連接後按 `help` 或 `status`。若 LCD `display` 沒有回覆，確認讀卡機已燒錄支援該指令的正式韌體。若需查看完整接線及韌體建置方法，參閱 CVTA 專案的韌體指南與現場測試文件。

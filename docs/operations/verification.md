# 安裝或更新後檢查

安裝、更新或調整讀卡設備後，依實際使用的元件逐項確認。測試刷卡前先告知管理員，避免把測試紀錄當成一般出勤紀錄。

1. **後端與管理頁：**依[啟停後端](server.md)確認程序、監聽埠與工作目錄；開啟管理頁登入，確認既有員工與近期紀錄可查。
2. **資料庫：**確認工作目錄的 `data/punch_hot.db` 是預期資料庫；若調整過資料位置，先依[備份與還原](backup.md)保留副本，再確認既有紀錄仍在。
3. **Windows 讀卡端：**依[桌面端設定](desktop-reader.md)核對後台 UUID、核准狀態、實卡打卡及後台紀錄；更新程式時確認原裝置身分和離線紀錄仍在。
4. **ESP32：**依[ESP32 設定](esp32-reader.md)確認 `selftest`、Wi-Fi、NTP、UID 校對、後台核准及實卡紀錄。更換零件時另依[韌體測試方法](https://github.com/ip1259/CVTA_clock_in_v2/blob/master/firmware/TESTING.md)檢查硬體。
5. **離線補送：**若這次變更涉及網路或讀卡端，依[離線紀錄與排障](offline.md)確認暫存、恢復補送及後台紀錄能對上。
6. **新增卡片：**在「卡片管理 → 新增卡片」各選一台已核准的 Windows 與 ESP32 讀卡端，待加卡提示出現後各刷一張測試卡；確認讀卡端成功提示、管理頁結果與自動更新的卡片清單一致，並確認該次刷卡沒有考勤紀錄或離線補送事件。另測試卡號已存在、網路回應無法確認，以及首次刷卡與 30 秒逾時後恢復打卡。

完成後在維運紀錄中記下日期、版本、實際測試結果與未解決問題；密碼、裝置密鑰及資料庫備份不要記在一般文件中。

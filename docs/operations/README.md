# 維運操作導覽

此目錄按操作任務分類。集中伺服器目前是 Windows 主機 `192.168.100.23`；後端與管理頁同機，桌面讀卡端可裝在接有實體讀卡機的 Windows 電腦，ESP32 可獨立供電運行。原始碼在 [GitHub 專案](https://github.com/ip1259/CVTA_clock_in_v2)。

| 要做的事 | 從這裡開始 |
| --- | --- |
| 查啟動捷徑、停止或重啟後端 | [啟停後端](server.md) |
| 人工備份或還原資料庫 | [備份與還原](backup.md) |
| 安裝或重新核准 Windows 讀卡端 | [設定桌面讀卡端](desktop-reader.md) |
| 接線、更換或設定 ESP32 讀卡端 | [設定 ESP32 讀卡端](esp32-reader.md) |
| 斷線後補送、查拒絕或異常打卡 | [離線紀錄與排障](offline.md) |
| 安裝或更新後確認系統 | [系統檢查](verification.md) |

操作前先依[啟停後端](server.md)確認工作目錄；`data/`、`logs/` 的位置由該目錄決定，不一定在 exe 所在目錄。其他項目依上表選擇對應教程。

目前尚未訂定備份頻率、保存位置、保留期間與負責人；啟動捷徑及工作目錄須以現場設定為準。
